Problems

Problem 1. Specific leaf area

Specific leaf area (SLA) is a measurement of leaf surface area (in mm2) divided by dry mass (in g) that indicates how a plant individual retains and uses resources. A high value for SLA represents a “fast” resource use strategy, while a low value for SLA represents a “slow” resource use strategy.

Specific leaf area can differ amongst species. You ask how SLA (measured as mm2/g) differs between coast live oaks (Quercus agrifolia, n = 13) and valley oaks (Quercus lobata, n = 11).

If you wanted to compare the SLA between these species based on the samples you collected,

  1. Would you want to compare means or medians? Why?
  2. Which test(s) could you use for either means or medians?
  3. What assumptions would you have to check for either test?
  4. How would you check them (i.e. using what tools)?
  5. What other values could you calculate? Be specific with a name and what it would tell you.

Problem 2. Root:shoot ratio

Root to shoot ratio, calculated as the dry mass of aboveground biomass (in g) divided by the dry mass of belowground biomass (in g) is another morphological characteristic that reveals a plant’s life history strategy. Plants from nutrient-poor areas tend to have lower root:shoot ratios because they tend to invest more resources in growing roots (to find more nutrients).

If you wanted to compare the root:shoot ratio of valley oak seedlings growing in nutrient-poor (n = 15), intermediate (n = 12), and nutrient-rich soils (n = 16),

  1. Would you want to compare means or medians? Why?
  2. Which test(s) could you use for either means or medians?
  3. What assumptions would you have to check for either test?
  4. How would you check them (i.e. using what tools)?
  5. What other values could you calculate? Be specific with a name and what it would tell you.
  6. What other test(s) could you run after the test(s) you listed in part b? Be specific with a name and what it would tell you.

Problem 3. Figure comparing groups

Write a caption for this figure using data from ntl_icecover in the lterdatasampler package.

# base layer: ggplot
ggplot(data = ntl_icecover,
       # x-axis: lake
       # y-axis: ice duration
       # color geometries by lake
       mapping = aes(x = lakeid,
                     y = ice_duration,
                     color = lakeid)) +
  # boxplot to represent medians
  geom_boxplot(outliers = FALSE) +
  # jitter to represent ice duration in a single year
  geom_jitter(height = 0,
              width = 0.2,
              shape = 21) +
  # relabelling axes
  labs(y = "Duration of ice cover (days per year)") +
  # custom colors
  scale_color_manual(values = c("orange2", "turquoise")) +
  # plot appearance changes
  theme(legend.position = "none",
        text = element_text(size = 16),
        axis.ticks = element_line(linewidth = 1),
        axis.title.x = element_blank(),
        panel.background = element_rect(fill = "white",
                                        color = "black",
                                        linewidth = 1),
        panel.grid = element_blank(),
        legend.key = element_rect(fill = "white",
                                  color = "white"))

Problem 4. Timeseries figure

Write a caption for this figure using data from ntl_airtemp in the lterdatasampler package.

# start with air temperature data set
ntl_airtemp |> 
  # group by year
  group_by(year) |>
  # calculate mean annual temperature in celcius
  summarize(ave = mean(ave_air_temp_adjusted)) |> 
  # ungroup data frame
  ungroup() |> 
  # pipe into ggplot
  # x-axis: year
  # y-axis: mean annual temperature
  ggplot(mapping = aes(x = year,
                       y = ave)) +
  # points to represent temperatures
  geom_point(color = "darkblue") +
  # lines to connect points
  geom_line(color = "darkblue") +
  labs(x = "Year",
       y = "Mean annual temperature (\U00B0 C)") +
  # plot appearance changes
  theme(text = element_text(size = 16),
        axis.ticks = element_line(linewidth = 1),
        panel.background = element_rect(fill = "white",
                                        color = "black",
                                        linewidth = 1),
        panel.grid = element_blank(),
        legend.key = element_rect(fill = "white",
                                  color = "white"))
