Do you think there is a linear relationship between air temperature and latitude? Be specific about the visual components (i.e. the points) that allow you to make this claim.

#| echo: false

pie_crab_clean <- pie_crab |> 
  select(latitude, air_temp) |> 
  distinct()

ggplot(data = pie_crab_clean,
       mapping = aes(x = latitude,
                     y = air_temp)) +
  geom_point(size = 2,
             color = "darkblue",
